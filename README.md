# Transportes Don Alfonso

Sitio web estático para empresa de transportes.

## Estructura
- `index.html` - Página principal
- `cookies.html`, `privacidad.html`, `reclamaciones.html`, `terminos.html` - Páginas legales
- `robots.txt`, `sitemap.xml`, `manifest.webmanifest` - SEO/PWA
- `.htaccess`, `nginx.conf.example` - Configuración servidor
- `DEPLOY.md` - Instrucciones de despliegue
